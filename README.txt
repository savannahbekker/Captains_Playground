Captain's Playground - install guide

STEP 1 - Put the game online (one time, free, about 5 minutes)
  1. Unzip this file on a computer. You get a folder of 7 files.
  2. Go to https://app.netlify.com/drop and create a free account.
  3. Drag the whole folder onto the page.
  4. Netlify gives you an address like https://something.netlify.app
     (you can rename it in Site settings, e.g. captains-playground.netlify.app).
  Send that address to anyone who should have the game.

STEP 2a - iPhone (Safari)
  1. Open the address in Safari (not Chrome, not the Claude app).
  2. Tap Share (square with arrow) > Add to Home Screen > Add.
  3. Open the game from the new icon. After the first open it works offline.

STEP 2b - Android (Chrome)
  1. Open the address in Chrome.
  2. Tap "Install app" when it pops up, or menu (three dots) > Install app
     (on some phones: Add to Home screen > Install).
  3. Open it from the app drawer / home screen. Works offline after the first open.

Notes
  - Progress is saved on each phone separately.
  - No ads, no tracking, no accounts needed to play.
  - To update the game later: drag the new folder onto your site in Netlify
    (Deploys > drag and drop). Phones pick up the update next time the game
    is opened with internet.
